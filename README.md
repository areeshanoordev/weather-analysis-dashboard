## How to Run Locally

1. Clone this repository.
2. Install the required libraries:

   pip install -r requirements.txt

3. Run the Streamlit application:

   streamlit run app.py
The dashboard allows users to filter weather observations by date, weather condition, and precipitation type. It also provides interactive charts to explore temperature trends, humidity, wind speed, and relationships between weather variables.
