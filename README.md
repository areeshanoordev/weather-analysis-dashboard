
# Weather Insights – Historical Weather Data Analysis

## Project Description

This project explores historical weather data from 2006 to 2016 using Python. It focuses on understanding temperature, humidity, wind speed, precipitation types, and relationships between different weather variables.

The project includes a Jupyter Notebook for data cleaning and analysis, along with an interactive Streamlit dashboard for exploring weather patterns.

## Tools and Libraries

- Python
- Pandas
- Plotly
- Streamlit
- Google Colab

## Key Findings

1. July had the highest average temperature, while January had the lowest.
2. Temperature and humidity showed a negative correlation.
3. Actual temperature and apparent temperature had a very strong positive correlation.
4. The year 2014 recorded the highest average yearly temperature in the dataset.

## Project Files

- `Weather_Data_Analysis.ipynb` – Data cleaning, exploration, analysis and visualizations.
- `app.py` – Interactive Streamlit dashboard.
- `weather_data.csv` – Historical weather dataset.
- `requirements.txt` – Required Python libraries.
